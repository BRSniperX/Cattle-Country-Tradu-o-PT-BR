# Cattle Country — Tradução PT-BR v1.0 - Switch


Primeira versão completa da tradução de **Cattle Country** para português do Brasil, para **Nintendo Switch (Atmosphère)** e **emuladores**.

## O que está traduzido

- Todos os diálogos, eventos e cenas (mais de 9.600 falas, cerca de 105 mil palavras)
- Cartas, missões, itens, receitas e menus
- Voz de cada personagem preservada: sotaques, gírias, bordões e erros propositais do original
- Nomes e apelidos adaptados (Xerife Tom, Will Selvagem, Jane Seis-Tiros…)
- Fonte do jogo com os acentos que faltavam: `ã õ ú Á Ã Í Ó Õ Ú`
- Placas da cidade redesenhadas: **XERIFE**, **ARMAZÉM**, **AÇOUGUE**, **PROMO**
- Tela de carregamento: "Carregando..."

## Requisitos

| | |
|---|---|
| Versão do jogo | **1.0.9** (atualização `v589824`) — obrigatória |
| Title ID | `0100A5B021446800` |
| Plataformas | Switch com Atmosphère · emuladores |

> ⚠️ O patch substitui o executável (`exefs/main`). Em qualquer outra versão do jogo ele não funciona e o jogo pode não abrir.

## Instalação

**Switch:** extraia `Cattle-Country-PTBR-v1.0-Switch.zip` na raiz do cartão SD.

```
SD:/atmosphere/contents/0100A5B021446800/exefs/main
SD:/atmosphere/contents/0100A5B021446800/romfs/Content/...
```

**Emulador:** botão direito no jogo → *Abrir local dos dados de mod* → extraia `Cattle-Country-PTBR-v1.0-Emulador.zip`.

```
load/0100A5B021446800/Cattle Country PT-BR/exefs/main
load/0100A5B021446800/Cattle Country PT-BR/romfs/Content/...
```

No jogo: **Configurações → Idioma → Português** (ocupa o lugar do Français).

## Problemas conhecidos

- Personagens criados antes do patch mantêm o nome automático antigo (ex.: "Cow-boy"); em jogo novo aparece "Vaqueiro"/"Vaqueira".
- Com o patch, alemão, japonês, chinês e coreano podem mostrar partes do texto em português. O inglês fica intacto.
- A plaquinha minúscula de "SALE" dentro da loja continua em inglês (a tradução não cabe no desenho).
